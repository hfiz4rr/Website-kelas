​🚀 Digital Memory X RPL 1 - SMKN 4 Kota Tangerang

​Sebuah proyek landing page interaktif yang dirancang sebagai pusat arsip dokumentasi dan informasi internal untuk kelas X RPL 1 di SMKN 4 Kota Tangerang. Website ini mengusung tema Modern Dark UI dengan fokus pada pengalaman pengguna (UX) yang bersih dan responsif.

​✨ Fitur Utama
​Modern Hero Section: Tampilan beranda dengan tipografi yang kuat dan navigasi yang intuitif.
​Organizational Structure: Visualisasi struktur kepengurusan kelas menggunakan komponen kartu yang elegan.
​Dynamic Memory Gallery: Galeri dokumentasi kegiatan yang dilengkapi dengan Sistem Filter Kategori (Lingkungan, Edukasi, Event).
​Fully Responsive: Optimal untuk diakses melalui perangkat mobile, tablet, maupun desktop.
​Glassmorphism Design: Implementasi efek blur dan transparansi modern pada elemen UI.

​🛠️ Teknologi yang Digunakan
​HTML5: Struktur semantik yang SEO-friendly.
​CSS3: Custom styling menggunakan CSS Variables, Flexbox, dan CSS Grid.
​JavaScript (ES6): Logika pemfilteran kategori galeri dan interaktivitas komponen.
​Google Fonts: Integrasi font 'Poppins' untuk tipografi yang profesional.
